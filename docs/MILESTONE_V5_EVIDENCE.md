# ProofJudge V5 — Compact Live Evidence

ProofJudge V5 adds ordered multi-milestone project chains on GenLayer. Each milestone escrows native GEN independently, and a later milestone cannot submit evidence until the previous milestone is PAID. V5 exposes machine-readable project progress and neutral participant settlement statistics.

V5 also ships a reusable TypeScript SDK for dApps and agents. The SDK reads jobs, lists project milestones, reads project progress and participant stats, audits settlement state, and builds requests for milestone creation, evidence submission, consensus resolution, challenge, claim, and refund.
